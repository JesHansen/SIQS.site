An open-source implementation of a classic integer-factorization algorithm.

SIQS.NET is both a factorization workbench and an explorable implementation of the self-initializing quadratic sieve. Use it from the command line, drive it through a Blazor web UI, or distribute the sieving phase across machines you control — all while the algorithm stays visible without being toy-sized.

How the quadratic sieve works

Factoring asks for non-trivial integers p and q with N = p × q. The quadratic sieve gets there by hunting for a congruence of squares.

X² ≡ Y² (mod N)
When X is not congruent to ±Y, gcd(X − Y, N) often exposes a factor. The hard part is building such a pair of squares efficiently.

Factor base

Choose primes for which the target has suitable quadratic-residue behavior.

Polynomial generation & sieving

Evaluate many values near a square root, adding logarithmic weights where factor-base primes divide them.

Relation collection

Retain values that factor over the base, including useful large-prime partial relations.

Filtering

Remove unhelpful rows and combine compatible partials to shrink the problem.

Linear algebra over GF(2)

Find a dependency in the parity vectors of prime exponents.

Square-root recovery

Turn that dependency into a congruence of squares and compute gcds for factors.

The “self-initializing” part refers to using multiple carefully constructed polynomials, so sieving continues efficiently without manually retuning each one.

Get started

Clone the repository, restore packages, and launch the web workbench — or factor a small number straight from the command line. 

# Requires the .NET 10 SDK
dotnet restore SIQS.slnx
dotnet run --project SIQS.UI/SIQS.UI.csproj --urls "http://0.0.0.0:5078"

# Then open http://localhost:5078

# Or factor a small integer from the CLI:
dotnet run --project QS/QS.csproj -- 15347
